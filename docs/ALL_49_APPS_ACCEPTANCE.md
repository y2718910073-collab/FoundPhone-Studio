# 49 App 全功能验收标准（必须逐项完成）

本项目目标不是复刻 49 个商业服务，而是做一台有真实内容、状态持久化、交互完整的可玩虚构手机。不得把占位卡片、无反应按钮、假加载、无法播放的媒体算作完成。

## 统一要求

每个 App 至少包括：主页面、内容详情、搜索或分类、核心创建/操作流程、历史/收藏/状态变化、跨页面持久化、空状态、错误反馈、移动端交互与自动化测试。没有内容的 App 不能用一条“测试内容”填充后宣称完成。

## 分类功能

- 电话、联系人、短信：拨号、原生 tel 跳转、模拟来电、拒接/接听、语音信箱、联系人增删改查、消息收发、会话记录与通知。
- 社交与聊天：动态列表、点赞、评论、转发、关注、私信、群聊、搜索、内容创建、时间线、用户主页、已读状态。
- Bilibili、YouTube、Netflix 风格视频：许可内容可播放、搜索、分类、播放历史、继续观看、收藏、进度、评论、推荐与错误处理。真实平台账号与商业片库需要各平台授权。
- 音乐：完整授权音频、播放列表、收藏、播放进度、顺序/随机/单曲循环、后台播放能力、搜索与历史。不能用几秒合成音代替完整音乐库。
- 相机、相册、文件：设备授权拍摄/上传、预览、删除、分组、重命名、导入导出与本地持久化。
- 浏览器、地图、天气：搜索与外部浏览、历史/书签、地图标记与路线、位置权限、天气来源与数据时间；模拟与真实数据分开标注。
- 购物、支付、外卖：商品目录、搜索、购物车、地址、模拟结算、订单生命周期、物流、评价、余额/账单；真实支付只能通过合法平台对接。
- 备忘录、日历、提醒、时钟、计算器、健康、查找、设置、App Store：核心编辑与计算流程、定时/日程、数据图表、虚构设备管理、主题设置、模拟安装与卸载、数据持久化。

## 完成定义

1. 按注册表列出全部 49 个 App，并给每个 App 写出功能检查清单。
2. 每个 App 至少三个不同交互测试，至少一个持久化测试。
3. 每个媒体条目都可播放或明确说明不可播放的原因。
4. 所有按钮有真实动作，不允许空操作。
5. 统一 IndexedDB 存储与迁移；新版本不能无提示丢失已有故事存档。
6. 所有业务边界诚实标注：剧情模拟、外部真实服务、设备原生能力。
7. 完整测试和部署成功后才标记为已完成。
