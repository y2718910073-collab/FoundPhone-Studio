# 玩家存档导出 / 导入

浏览器右下角的「存档」菜单可导出 JSON 备份，并在另一台设备导入。

- 存档只在玩家点击「导出存档」时生成并下载，不上传到任何服务器。
- 导入前会验证文件结构、作品 ID、revision 和媒体安全性；不兼容的故事或更新版本不会覆盖现有存档。
- 导入成功后会刷新页面，从 IndexedDB 读取恢复的进度。
- 导入会覆盖该作品在此浏览器的旧进度，导入前会再次确认。
- 备份上限为 2 MB；不要把玩家自己的存档上传到公开仓库。

开发自检：`npm run typecheck`、`npm run lint`、`npm test`、`npm run build`；真机 Safari 的下载和导入需要额外验证。
